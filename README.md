# 🗺️ 인천 동선 맛집 지도

출발지와 도착지를 정하면 **가는 길 위에 있는 인천 맛집**을, 지역구를 고르면 **그 동네 맛집 전체**를, **내 위치 반경**이나 **지하철 노선·역 반경**으로 보면 **가까운 순·추천순**으로 보여 주는 정적 웹앱입니다.
기본 256곳에 더해 **친구들이 직접 고른 맛집**이 쌓이고, `＋ 맛집 추천`을 열면 **`🏆 친구 추천 현황`**(누가 몇 곳을 추천했는지 랭킹)과 등록 폼이 한자리에 있습니다. 랭킹에서 이름을 누르면 그 친구 추천만 모아 볼 수 있습니다(v10).
API 키 없이도 동작하고, `assets/config.js`에 넣어 둔 **카카오 JavaScript 키**로 지도가 진짜 카카오맵으로, **Firebase Firestore**로 친구들과 실시간 공유됩니다.

- 서비스 주소: https://seongkuy0427-blip.github.io/incheon-food-map/
- 수록: 인천 맛집 **256곳** — 2차 확장(2026-11-26)으로 107곳을 추가했고, 특히 **계양구 9→31곳 · 부평구 18→41곳**으로 보강했습니다. 여기에 친구 추천이 더해집니다.
- 지역: 인천 (구조상 `region` 필드로 다른 지역을 추가할 수 있습니다)

## v10 — 추천 현황은 모달 안으로, 헤더 정리 (2026-11-27)

- **`🏆 친구 추천 현황` 이동**: 왼쪽 패널(/모바일 시트)에 늘 떠 있던 노란 박스를 없애고, `＋ 맛집 추천` 모달 맨 위 카드로 옮겼습니다. 모달을 열면 **추천 현황 + 등록 폼**이 한 화면에 있습니다.
- **칩 클릭 = 필터 + 모달 닫힘**: 모달 안에서 친구 이름을 누르면 그 친구 추천만 지도·목록에 남기고 창이 바로 닫힙니다. 그때만 목록 위에 `🏆 ○○ 님 추천 N곳 · [전체 보기 ✕]` 배너가 뜨고, `전체 보기`로 원래 보기로 돌아갑니다.
- **상단 `🔑 카카오 키` 버튼 제거**: `assets/config.js`에 기본 키가 들어 있어 헤더에서 뺐습니다(PC·모바일). 키를 직접 넣을 일이 있으면 `＋ 맛집 추천` 모달 맨 아래 **`카카오 키` 고급 설정**을 펼쳐 쓰면 됩니다. 기본 키가 적용 중이면 상태가 `기본 키 적용됨`으로만 조용히 표시됩니다.
- **예시 문구 중립화**: 이름 입력 예시는 `예: 홍길동`, 안내는 `이 이름으로 추천 배지와 랭킹이 매겨집니다.`

## v9 — 친구 추천·랭킹·공용 DB (2026-11-27)

- **초간단 등록**: `＋ 맛집 추천` → ① 내 이름 ② 가게 검색 ③ 한 줄 평(선택). 예전의 지역구·업종·메뉴·주소·전화 입력은 없앴고, 검색 결과에서 고르면 자동으로 채워집니다.
- **기존 집에 추천 더하기**: 친구가 이미 추천했거나 기본 256곳에 있는 집을 고르면 **새 가게를 만들지 않고** 그 집에 추천인·한 줄 평을 더합니다. 상세 패널의 **`＋ 나도 이 집 추천`** 으로도 됩니다.
- **`🏆 친구 추천 현황`**: `전체 (N)` + 추천인별 등록 수(내림차순, 1~3위 메달). 누르면 그 친구 추천만 모아 지도·목록에 표시하고, 모바일에서는 시트가 한 단계 올라옵니다.
- **배지**: 지도 핀 골드 링 + `○○ 추천` 태그, 카드·상세에 금색 `○○ 추천` 배지, 카드에 첫 한 줄 평. 같은 집을 여러 명이 추천하면 `○○ 외 1 추천` / 상세에 추천인별 한 줄 평 목록.
- **삭제 권한**: 추천은 **내 이름으로 등록한 것**(또는 방금 등록한 것)만 삭제 버튼이 보입니다. `지도에서 숨기기`는 예전처럼 내 브라우저에만 적용됩니다.
- **공용 DB**: Firestore `shared_places` 컬렉션을 실시간 구독. 연결 전에는 `recsCache.v1`의 마지막 사본을 보여 주고, 연결이 실패하면 로컬 저장으로 계속 씁니다. 이때 올린 추천은 `pending.v1`에 보관했다가 **연결이 돌아오면 자동으로 업로드**합니다. 등록 문서 필드는 `name·lat·lng·address·district·category·phone·note·recommender·placeRef·createdAt`입니다.

- **역 레일**: 세로 노선 라인 위에 역 점이 순서대로 놓이고, **환승역은 상대 노선 색 점**을 함께 표시합니다. 오른쪽에는 그 역 반경 안 맛집 수 배지, 선택한 역은 노선색 틴트 + 채운 점으로 강조되고 목록이 자동으로 그 위치로 스크롤됩니다.
- **지도 위 역 점**: 흰 속 + 노선색 링(환승역은 큰 점), 줌 13 이상이면 역 이름 라벨, 환승역·선택역은 항상 라벨. 선택역은 채운 점 + 노선색 이름 필로 바뀝니다.
- **요약 배너**: 모드 색의 은은한 그라데이션 + 왼쪽 4px 포인트 보더 + 큰 숫자(`27곳`) 강조.
- **업종 칩**: `🍚 한식 · 🍲 국밥 · 🥟 중식 · 🍣 일식 · 🍝 양식 · 🦐 해산물 · 🥩 고기 · 🍜 면·분식 · ☕ 카페·디저트` 이모지, 선택하면 업종별 컬러(예: 국밥 `#B45309`)로 채워집니다.
- **카드**: 순번 배지·세부 배지 채도 상향, 선택 카드는 모드 색 **좌측 포인트 바 + 소프트 틴트 배경 + 컬러 순번 배지**로 강조.
- **타이포·색**: Pretendard 가변폰트, 배경 `#F6F7F9` / 카드 `#FFFFFF` / 1px 헤어라인 `rgba(15,23,42,.08)`, 모서리 14~20px, 그림자 `0 8px 24px rgba(15,23,42,.06)`.
- **PC**: 52px 반투명 글래스 헤더 + 지도 위에 떠 있는 좌측 플로팅 패널(392px) + 잡지형 우측 상세 카드. 지도 맞춤(fitTo)은 패널에 가리지 않는 영역 기준. 상세가 열리면 지도 컨트롤이 드로어 왼쪽으로 비켜납니다.
- **모바일**: 상단 플로팅 글래스 바(브랜드 + 키/추가) 아래 **4칸 모드 스트립** · 풀스크린 지도 · 손잡이로 3단(34% / 50% / 88%) 조절되는 바텀시트. 상세는 아래에서 올라오는 시트(최대 74dvh, 핸들 드래그로 닫기)이고 시트 위쪽 지도는 계속 조작됩니다.
- **지도**: 경로는 인디고 3중 레이어(글로우 15px → 화이트 케이싱 8px → 메인 4px), 출발은 다크 슬레이트 링, 도착은 코랄 핀. 맛집 핀은 흰 테두리 + 드롭 섀도우, 선택 시 확대 + 펄스 링, 이름 라벨은 반투명 화이트 + `backdrop-filter: blur(6px)`.
- **지도 엔진**: `assets/app.js`의 어댑터 한 겹(`createLeafletEngine` / `createKakaoEngine`)이 `setView·flyTo·fitTo·polyline·circle·overlay`를 감싸서, 모드·필터·핀 클릭·반경 원·라벨 배치가 두 엔진에서 같은 코드로 돌아갑니다. 핀·라벨은 양쪽 모두 같은 HTML(`.ov` + `.pin` + `.ov-label`)을 씁니다.

## 사용한 공개 서비스

- 지도: [Leaflet](https://leafletjs.com) + © OpenStreetMap contributors (타일 `tile.openstreetmap.org`) — 기본 지도(폴백)
  - 2026-11 기준 CartoDB Positron 타일은 `API KEY REQUIRED` 워터마크가 찍혀 쓸 수 없어, OSM 타일에 **CSS 컬러 그레이딩**(`saturate(.14) brightness(1.06) contrast(.9) hue-rotate(-4deg)`, 타일 팬에만 적용)만 입혀 애플지도 같은 실버 톤으로 씁니다.
- 지도(기본): **카카오맵 JavaScript SDK** `dapi.kakao.com/v2/maps/sdk.js?libraries=services` — `assets/config.js`의 **도메인 제한 JavaScript 키**(또는 브라우저에 넣은 키)로 로드합니다. 키가 없거나 허용 도메인이 맞지 않으면 OSM으로 폴백합니다.
- 공용 DB(v9): **Firebase Firestore** (compat SDK 10.14.1, `shared_places` 실시간 구독·등록·삭제) — 설정·보안 규칙은 `FIREBASE.md`.
- 자동차 경로: [OSRM](https://project-osrm.org) 공개 라우터 `router.project-osrm.org` (데모 서버라 응답이 느리거나 없을 수 있음 → 직선 폴백)
- 장소 검색: OpenStreetMap [Nominatim](https://nominatim.org) · (선택) 카카오 로컬 키워드 검색 API `dapi.kakao.com` — 사용자가 자기 브라우저에 넣은 REST API 키로만 호출

## 카카오 키·공용 DB 설정 (`assets/config.js`)

`assets/config.js` 한 파일에 배포용 키를 모아 둡니다. 이 파일은 GitHub Pages로 공개되므로 **도메인 제한을 건 공개용 키만** 넣습니다.

```js
window.APP_CONFIG = {
  kakaoJsKey: "…JavaScript 키…",   // 카카오 디벨로퍼스 → Web 사이트 도메인에 https://seongkuy0427-blip.github.io 등록
  firebase: { apiKey: "…", projectId: "…", appId: "…", … }  // 없으면 null
};
```

- `kakaoJsKey`가 있으면 친구들은 키 입력 없이 **카카오맵 지도 + 상호명 검색(Places)** 을 씁니다. 브라우저에 따로 넣은 키(`＋ 맛집 추천` 모달 맨 아래 `카카오 키` 고급 설정)가 있으면 그 값이 우선입니다.
- `firebase`가 있으면 **모든 방문자가 같은 추천 목록**을 실시간으로 봅니다. `null`이면 예전처럼 이 기기에만 저장됩니다.
- 자세한 준비 절차·Firestore 보안 규칙은 **`FIREBASE.md`**.

## 카카오 키를 브라우저에서 직접 넣는 법 (예전 방식)

1. <https://developers.kakao.com> 로그인 → **내 애플리케이션** → `인천맛집지도` 앱 선택
2. **앱 → 플랫폼 키**: **REST API 키**(상호명 검색용)와 **JavaScript 키**(지도용)를 각각 복사
3. `＋ 맛집 추천` 모달 맨 아래 **`카카오 키`** 고급 설정을 펼쳐 → `REST API 키`·`JavaScript 키` 칸에 붙여넣고 각각 **저장** — 휴대폰·PC에서 각각 한 번씩
4. 지도가 안 뜨면 **플랫폼 → Web 사이트 도메인**에 `https://seongkuy0427-blip.github.io` 가 들어 있는지 확인

키는 그 브라우저의 `localStorage`(`kakaoRestKey` / `kakaoJsKey`)에만 저장되고 GitHub에는 올라가지 않습니다. JavaScript 키를 저장하면 그 자리에서 카카오맵으로 전환하고, 실패하면 미등록 키 안내와 함께 **기본 지도(OSM)** 로 되돌아갑니다(앱은 그대로 쓸 수 있음). REST 키는 카카오 로컬 API 하루 30만 건까지 무료이며, 키가 없거나 오류(401/403)면 도로명주소 검색으로 자동 폴백합니다.
