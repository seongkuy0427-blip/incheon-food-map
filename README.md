# 🗺️ 인천 동선 맛집 지도

출발지와 도착지를 정하면 **가는 길 위에 있는 인천 맛집**을, 지역구를 고르면 **그 동네 맛집 전체**를, **내 위치나 고른 지점 반경 1·3·5km**로 보면 **가까운 순서**로 보여 주는 정적 웹앱입니다.
API 키 없이 바로 동작하고, 휴대폰·PC 모두에서 같은 화면을 씁니다.

- 서비스 주소: https://seongkuy0427-blip.github.io/incheon-food-map/
- 수록: 인천 맛집 **256곳** — 2차 확장(2026-11-26)으로 107곳을 추가했고, 특히 **계양구 9→31곳 · 부평구 18→41곳**으로 보강했습니다.
- 지역: 인천 (구조상 `region` 필드로 다른 지역을 추가할 수 있습니다)

## 기능

| 기능 | 설명 |
| --- | --- |
| 세 가지 보기 | **🛣️ 동선 내 맛집** — 출발·도착·이동수단·반경 기준, 지역구 구분 없이 경로 위 맛집 표시(정렬을 `경로에서 가까운 순 ⇄ 출발→도착 순`으로 전환)<br>**🗺️ 지역구 내 맛집** — 동선과 무관하게 고른 구의 맛집 전체 표시, 구를 바꾸면 지도가 그 동네로 이동<br>**📍 내 주변 맛집** — GPS·장소 검색·지도 클릭으로 기준 위치를 잡고 반경 **1·3·5km(기본 3km)** 안의 맛집을 **가까운 순(0.4km 등)**으로 표시, 지도에 기준 핀 + 반투명 인디고 반경 원 표시 |
| 출발·도착 지정 | 주요 거점 칩 14개, 장소·주소 검색(카카오 상호명 검색 + OpenStreetMap Nominatim), 지도 클릭, 현재 위치(GPS) |
| 🔑 카카오 상호명 검색 (선택) | 카카오 디벨로퍼스 **REST API 키를 한 번 넣으면** 가게 이름만으로 검색됩니다. 결과를 누르면 **가게명·주소·좌표·지역구·업종·전화번호**가 자동으로 채워집니다. 키는 코드·저장소가 아니라 **그 브라우저의 `localStorage`(`kakaoRestKey`)에만** 저장되고, 키가 없거나 401/403이면 기존 도로명주소(Nominatim) 검색으로 자동 폴백합니다. |
| 이동 수단 | 🚗 자동차: OSRM 공개 라우팅으로 실제 도로 경로·거리·예상 시간 계산 (응답이 없으면 직선 폴백)<br>🚇 대중교통: 노선·환승 정보 없이 **출발→도착 직선 축**과 역·거점을 표시 |
| 동선 반경 | 경로 폴리라인까지의 최단 수직 거리로 500m / 1km / 2km / 전체 필터 |
| 내 주변 반경 | 기준 위치에서 1km / 3km / 5km(기본) — 지도 반경 원에 맞춰 자동 fitBounds |
| 업종 2단 필터 | **전체 / 식사 / 카페·디저트** → 식사에서는 **한식·국밥·중식·일식·양식·해산물·고기·면·분식** 다중 선택 |
| 세부 배지 | 카드·상세의 배지는 뭉뚱그린 '로컬' 대신 실제 구분(**미쉐린·블루리본·백년가게·방송맛집·노포·국민맛집·찐후기·내 맛집**)을 파스텔 소프트 필 색으로 표시 |
| 카드·핀 연동 | 목록 카드를 누르면 지도가 그 가게로 **부드럽게 이동(flyTo)** 하고 우측 상세 패널이 열립니다. 지도 핀을 눌러도 같은 상세가 열립니다. 선택 핀은 크게 + 펄스로 강조되고 이름 라벨이 붙습니다. |
| 핀 이름 라벨 | 화면에서 겹치지 않는 범위에서 가게 이름을 상시 표시하고, 나머지는 마우스를 올리면 보입니다. 확대·이동하면 라벨이 다시 배치됩니다. |
| ⭐ 내 맛집 추가 | 가게·주소 검색 또는 **지도에서 직접 클릭**해 위치를 찍고 가게명·지역구·업종·대표 메뉴·메모·전화 저장. `localStorage`에 저장되어 목록·지도·필터에 바로 반영되고 삭제할 수 있습니다. |
| 백업·불러오기 | PC↔휴대폰 공유용 `내 맛집 백업(JSON)` / `불러오기` |
| 숨기기 | 모든 가게 상세에서 `지도에서 숨기기` → 목록·지도에서 즉시 제외, 숨긴 가게가 있을 때만 나타나는 `숨긴 가게 N곳 복원` 배너로 되살리기 |
| 상세 패널 | 등급, 주소, 대표 메뉴·가격, 광고 뺀 후기 요약, 영업·휴무·이용 팁, 전화, 출발지로/도착지로, 작은 길찾기 링크(네이버·카카오) |

## 디자인 (v5, 2026-11-26)

- **타이포·색**: Pretendard 가변폰트, 배경 `#F6F7F9` / 카드 `#FFFFFF` / 1px 헤어라인 `rgba(15,23,42,.08)`, 모서리 14~20px, 그림자 `0 8px 24px rgba(15,23,42,.06)`.
- **PC**: 52px 반투명 글래스 헤더 + 지도 위에 떠 있는 좌측 플로팅 패널(392px) + 잡지형 우측 상세 카드. 지도 맞춤(fitBounds)은 패널에 가리지 않는 영역 기준.
- **모바일**: 상단 플로팅 글래스 바(브랜드 + 동선/지역구 전환 + 키/추가) · 풀스크린 지도 · 손잡이로 3단(34% / 50% / 88%) 조절되는 바텀시트. 상세는 아래에서 올라오는 시트(핸들 드래그로 닫기).
- **지도**: 경로는 인디고 3중 레이어(글로우 15px → 화이트 케이싱 8px → 메인 4px), 출발은 다크 슬레이트 링, 도착은 코랄 핀. 맛집 핀은 흰 테두리 + 드롭 섀도우, 선택 시 확대 + 펄스 링, 이름 라벨은 반투명 화이트 + `backdrop-filter: blur(6px)`.

## 등급 기준 (중요)

- **블루리본** — 블루리본 서베이 2025 인천 선정작 중 이 지도에 수록된 곳.
- **백년가게** — 중소벤처기업부·소상공인시장진흥공단이 업력 30년 이상 가게 중 선정한 곳.
- **방송 맛집** — `<식객 허영만의 백반기행>` 인천편, 풍자 `<또간집>`, 성시경 `<먹을텐데>`, `<6시 내고향>` 등에 소개된 곳.
- **노포** — 인천관광공사가 소개한 1960~70년대 개업 가게.
- **국민맛집** — kmra.co.kr 국민맛집 인천 목록에서 확인 후 카카오맵으로 재검증한 곳.
- **찐후기** — 광고·협찬 없이 방문자 후기와 지역 자료로 검증한 곳. 카카오맵 리뷰 원문의 칭찬과 불만을 함께 요약했습니다.
- **미쉐린** — ⚠️ 미쉐린 가이드 한국판은 **서울·부산만** 평가합니다(2025·2026 에디션 모두 인천 미포함).
  그래서 이 등급은 "인천에서 미쉐린 선정을 받은 식당"이 아니라 **미쉐린 스타 레스토랑 출신 셰프·브랜드가 인천에서 운영하는 곳**을 뜻합니다.

## 데이터

- `data/restaurants.json` — 256곳. 2차 확장분은 `sourceNote`에 카카오맵 리뷰 수·평점을 남겼습니다. 필드: `id, name, region, district, districtOld, dong, tier, tierLabel, tierNote, category, categoryGroup, address, lat, lng, menus, reviewSummary, tips, hours, closed, phone, naverMapUrl, kakaoMapUrl`
- `category`는 **한식·국밥·중식·일식·양식·해산물·고기·면·분식·카페·디저트** 9종으로 표준화했고, `categoryGroup`이 `meal`/`cafe`를 구분합니다.
- 좌표·도로명주소는 카카오맵 장소 패널에서 확인했고, 영업 상태가 확인되는 곳만 넣었습니다.
- **지역구 이름은 2026년 7월 1일 인천 행정체제 개편을 반영**했습니다.
  중구 내륙+동구 → **제물포구**, 중구 영종도 → **영종구**, 서구 → **서해구**, 검단 → **검단구**.
  (카드에는 옛 이름을 괄호로 함께 표시)
- 출처·검증 방법은 `data/SOURCES.md`에 정리했습니다. 영업시간·휴무·가격은 방문 전 매장 공지 확인이 필요합니다. 데이터 기준일: 2026-11-26.

## 로컬에서 열기

```bash
cd incheon-food-map
python3 -m http.server 8000
# http://127.0.0.1:8000
```

`data/restaurants.json`을 `fetch`로 읽기 때문에 `file://`로 바로 열면 데이터가 뜨지 않습니다. 간단한 정적 서버로 열어 주세요.

## 사용한 공개 서비스

- 지도: [Leaflet](https://leafletjs.com) + © OpenStreetMap contributors (타일 `tile.openstreetmap.org`)
  - 2026-11 기준 CartoDB Positron 타일은 `API KEY REQUIRED` 워터마크가 찍혀 쓸 수 없어, OSM 타일에 **CSS 컬러 그레이딩**(`saturate(.14) brightness(1.06) contrast(.9) hue-rotate(-4deg)`, 타일 팬에만 적용)만 입혀 애플지도 같은 실버 톤으로 씁니다.
- 자동차 경로: [OSRM](https://project-osrm.org) 공개 라우터 `router.project-osrm.org` (데모 서버라 응답이 느리거나 없을 수 있음 → 직선 폴백)
- 장소 검색: OpenStreetMap [Nominatim](https://nominatim.org) · (선택) 카카오 로컬 키워드 검색 API `dapi.kakao.com` — 사용자가 자기 브라우저에 넣은 REST API 키로만 호출

## 카카오 상호명 검색 키 넣는 법 (3단계)

1. <https://developers.kakao.com> 로그인 → **내 애플리케이션** 추가(이름은 아무거나)
2. 만든 앱의 **앱 키**에서 **REST API 키** 복사
3. 앱의 `🔑 카카오 키`(또는 `⭐ 내 맛집 추가` → `🔑 카카오 상호명 검색 키`) 칸에 붙여넣고 **저장** — 휴대폰·PC에서 각각 한 번씩

키는 그 브라우저의 `localStorage`에만 저장되고 GitHub에는 올라가지 않습니다. 카카오 로컬 API는 하루 30만 건까지 무료이며, 키가 없거나 오류(401/403)면 도로명주소 검색으로 자동 폴백합니다.
