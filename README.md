# 🗺️ 인천 동선 맛집 지도

출발지와 도착지를 정하면 **가는 길 위에 있는 인천 맛집**을 등급·거리·진행 순서로 골라 주는 정적 웹앱입니다.
API 키 없이 바로 동작하고, 휴대폰·PC 모두에서 같은 화면을 씁니다.

- 서비스 주소: https://seongkuy0427-blip.github.io/incheon-food-map/
- 수록: 인천 맛집 **40곳** (블루리본 12 · 찐후기 26 · 미쉐린 스타 브랜드/셰프 2)
- 지역: 인천 (구조상 `region` 필드로 서울 등 다른 지역을 추가할 수 있습니다)

## 기능

| 기능 | 설명 |
| --- | --- |
| 출발·도착 지정 | 주요 거점 칩 14개, 장소·주소 검색(내장 사전 + OpenStreetMap Nominatim), 지도 클릭, 현재 위치(GPS) |
| 이동 수단 | 🚗 자동차: OSRM 공개 라우팅으로 실제 도로 경로·거리·예상 시간 계산 (응답이 없으면 직선 폴백)<br>🚇 대중교통: 키 없이 도는 버전이라 노선·환승 정보가 없어 **출발→도착 직선 축**으로 표시하고 역·거점을 함께 보여 줍니다 |
| 동선 반경 | 경로 폴리라인까지의 최단 수직 거리로 500m / 1km / 2km / 전체 필터 |
| 등급 필터 | 미쉐린 · 블루리본 · 찐후기 (다중 선택) + 지역구 필터 |
| 정렬 | 경로 진행 순서(출발→도착) |
| 맛집 카드 | 등급 배지, 카테고리, **경로에서 몇 m**, 대표 메뉴와 가격대, 광고 뺀 후기 요약, 영업·휴무·주차 팁, 네이버지도·카카오맵 바로가기 |

## 등급 기준 (중요)

- **블루리본** — 블루리본 서베이 2025 인천 선정작 중 이 지도에 수록된 곳.
- **찐후기** — 광고·협찬 없이 방문자 후기와 지역 자료로 검증한 곳. 노포·시장 먹거리·동네 단골집 중심.
- **미쉐린** — ⚠️ 미쉐린 가이드 한국판은 **서울·부산만** 평가합니다(2025·2026 에디션 모두 인천 미포함).
  그래서 이 등급은 "인천에서 미쉐린 선정을 받은 식당"이 아니라 **미쉐린 스타 레스토랑 출신 셰프·브랜드가 인천에서 운영하는 곳**을 뜻합니다.
  각 카드의 '등급 근거'에 그 이유를 적어 두었습니다.

## 데이터

- `data/restaurants.json` — 40곳. 필드: `id, name, region, district, tier, tierLabel, category, address, lat, lng, menus, reviewSummary, tips, hours, closed, phone, naverMapUrl, kakaoMapUrl`
- 좌표는 카카오맵 장소 좌표를 도로명주소와 대조해 확인했습니다(건물 단위, 오차 수십 m 이내).
- **지역구 이름은 2026년 7월 1일 인천 행정체제 개편을 반영**했습니다.
  중구 내륙+동구 → **제물포구**, 중구 영종도 → **영종구**, 서구 → **서해구**, 검단 → **검단구**.
  (카드에는 옛 이름을 괄호로 함께 표시)
- 영업시간·휴무·가격은 방문 전 매장 공지 확인이 필요합니다. 데이터 기준일: 2026-11-26.

## 로컬에서 열기

```bash
cd incheon-food-map
python3 -m http.server 8000
# http://127.0.0.1:8000
```

`data/restaurants.json`을 `fetch`로 읽기 때문에 `file://`로 바로 열면 데이터가 뜨지 않습니다. 간단한 정적 서버로 열어 주세요.

## 사용한 공개 서비스

- 지도: [Leaflet](https://leafletjs.com) + © OpenStreetMap contributors (타일 `tile.openstreetmap.org`)
- 자동차 경로: [OSRM](https://project-osrm.org) 공개 라우터 `router.project-osrm.org` (데모 서버라 응답이 느리거나 없을 수 있음 → 직선 폴백)
- 장소 검색: OpenStreetMap [Nominatim](https://nominatim.org)
